# 말랑 산장 v2 — "하얀 부엉이 저택 사건" 설계

작성일: 2026-11-21 · 상태: 승인됨 (블록 스타일로 변경 후 사용자 "좋아")

## 1. 왜 다시 만드나
v1(`index.html`, 배포: https://ahbin-cho.github.io/mystery-room-3d/)은 동작은 하지만 사용자 평가가 "허접하다".
사용자가 짚은 세 가지:
- **캐릭터가 허접하다** — 도형 두 개 + 색 차이뿐
- **사건이 쉽고 단순하다** — 증거 하나가 범인을 바로 가리킴, 범인 외엔 수상할 이유가 약함
- **공간·소품·이동이 빈약하다** — "클루 같은 단순한 게임도 방이 다양하고 소품이 많고 이동이 있다"

v2의 목표: 친구 4명이 각자 집에서 폰으로 들어와 **30~40분 동안 넓은 저택을 돌아다니며, 모두가 서로를 의심하는** 크라임씬.

## 2. 목표 / 비목표 / 실패 기준
**목표**
- 방 10개 이상, 2개 층, 계단, 비밀 통로가 있는 저택 (사용자 선택: C안 = 맵 확장 + 조이스틱)
- 방마다 소품 15~30개, 열어 볼 수 있는 곳(서랍·옷장·가방·금고)에 증거가 숨어 있음
- 애니메이션 있는 캐릭터 (걷기/대기/앉기 등), 역할마다 다른 외형
- **모두가 수상한 사건** (사용자 요구): 범인이 아닌 3명도 그날 밤 숨기고 싶은 짓을 했고 흔적이 남음
- 증거 하나로는 못 풀고 **2~3개를 조합**해야 범인이 좁혀짐, 반전 1개
- v1의 멀티(PeerJS, 방 코드, 방장 진행), 수첩, 증거 챙기기/공개, 투표, 진상 공개 흐름 유지

**비목표**
- 음성 채팅 (보이스톡/디스코드 사용)
- 계정, 서버, 랭킹
- 시나리오 여러 개 (v2는 사건 1개. 단, 시나리오 파일을 분리해 추가가 쉽게)

**실패 기준 (동작해도 실패인 것)**
- 폰에서 버벅여서 걷기가 답답함 (중급 안드로이드에서 30fps 미만)
- 첫 로딩이 와이파이에서 10초 이상
- 증거 하나만 보고 범인을 맞힐 수 있음
- 맵이 넓어졌는데 길을 잃음 (어느 방인지 모름)

## 3. 접근 방식
| 안 | 내용 | 장단점 | 결정 |
|---|---|---|---|
| A | 전부 코드 도형(둥근 클레이), 파일 하나 | 가볍지만 "도형 조립" 느낌이 남아 허접함 해결 안 됨 | 기각 |
| B | CC0 로우폴리 에셋(Kenney) + 파일 분리 | 퀄리티 상승, 다운로드·로딩 증가 | 처음 선택 → 아래 V로 변경 |
| C | AI 생성 이미지를 판으로 세움 | 3D 공간엔 어색 | 기각 |
| **V** | **블록(복셀) 세상을 코드로 직접 생성 + 파일 분리** — "마인크래프트로 크라임씬 맵을 지은 듯한" 느낌 (사용자 요청) | 블록이 원래 스타일이라 도형 느낌이 장점이 됨. 소품을 블록 수백 개로 촘촘히 채워도 인스턴싱으로 가벼움. 다운로드 없음. 단점: 픽셀 텍스처·블록 소품을 전부 직접 디자인해야 함 | **사용자 선택 (최종)** |

마인크래프트의 실제 텍스처·캐릭터(스티브, 크리퍼 등)·로고는 쓰지 않는다. 블록 감성만 빌린 **자체 픽셀 스타일**.

## 4. 정한 것
### 4.1 기술
- Three.js 0.160 (importmap, unpkg), PeerJS 1.5.4 — v1과 동일. 외부 3D 모델 없음
- 빌드 도구 없음. GitHub Pages(`main` 루트)에 그대로 배포
- 파일 구조 (제안):
  ```
  index.html            진입점, importmap, CSS
  src/main.js           부팅, 루프
  src/net.js            PeerJS 방장-권한 스타 구조 (v1 로직 이전)
  src/world.js          층/방/벽/문/계단/비밀통로 생성 (데이터 기반)
  src/voxel.js          블록 팔레트(블록 종류 → 픽셀 텍스처), InstancedMesh로 블록 일괄 렌더, 충돌 격자
  src/textures.js       16×16 픽셀 텍스처를 캔버스로 생성 (나무결, 벽돌, 타일, 카펫, 책 등)
  src/props.js          블록 소품 프리팹 (책장, 식탁, 피아노, 침대, 화분 …) — 작은 블록 배열 데이터
  src/characters.js     블록 사람 (머리·몸통·팔·다리 박스) + 걷기/대기/쪼그리기 코드 애니메이션, 역할별 외형
  src/controls.js       가상 조이스틱 + 탭 이동/길찾기
  src/ui.js             HUD, 수첩, 증거 카드, 투표, 진상
  src/cases/owl-manor.js  사건 데이터(역할, 증거, 진상, 맵 배치)
  ```
- 이번 v2가 v1 `index.html`을 대체. v1은 git 기록에 남음

### 4.2 비주얼 — 블록 세상
- **기본 단위**: 큰 블록 1칸 = 0.5m (벽·바닥·큰 가구). 소품은 1/4 크기 미니 블록(0.125m)으로 세밀하게 (책, 컵, 접시, 촛대, 귀걸이 등)
- **텍스처**: 16×16 픽셀 텍스처를 코드로 그림, `NearestFilter`로 또렷한 픽셀감. 팔레트는 따뜻한 저택 톤(호두나무, 크림 벽지, 와인색 카펫, 녹색 온실 타일)
- **조명**: 밤 + 방마다 따뜻한 점광원(샹들리에·스탠드·벽난로), 창밖 푸른 눈빛. 서재는 어둡게 + 노란 폴리스 라인 블록
- **밀도**: 방마다 소품 15~30개(블록 수백 개). 같은 블록 종류는 InstancedMesh로 묶어 그림 → 층 하나 기준 드로우콜 목표 100 이하
- **캐릭터**: 블록 사람(머리 8px 정사각, 몸통, 팔다리 박스). 얼굴·옷은 픽셀 텍스처. 역할별 실루엣: 유진(남, 안경, 갈색 코트), 한별(여, 단발, 후드티, 은색 링 귀걸이), 도윤(남, 검은 집사복, 흰 장갑), 세라(여, **긴 머리**, 진주 귀걸이, 빨간 숄), 조수 탐정(트렌치코트, 모자). 걷기 시 팔다리 흔들기, 대기 시 숨쉬기, 조사 시 쪼그리기
- **증거 상세 보기**: v1의 분해(teardown) 미니 뷰를 블록 버전으로 — 블록이 흩어졌다 모이며 회전
- 외부 다운로드 없음

### 4.3 조작·이동 (사용자 선택 C)
- 왼쪽 아래 **가상 조이스틱**으로 직접 걷기 (주 조작)
- 물건/문/계단 **탭** → 자동으로 걸어가서 상호작용 (v1 길찾기를 방-문 그래프로 확장)
- **계단**: 홀 계단에 닿으면 페이드 후 다른 층으로 이동. 현재 층만 보이고 다른 층은 숨김
- **비밀 통로**: 서재 책장 ↔ 온실 화분대. 처음엔 숨겨져 있고, 서재 책장의 "어긋난 책"을 조사하면 발견 → 발견한 사람부터 사용 가능, "공개"하면 모두 사용 가능
- 카메라: 3인칭 위쪽 시점(v1 유지). 카메라와 캐릭터 사이 벽은 반투명 처리
- 방 이름: 방에 들어설 때 상단에 방 이름 표시 + 수첩에 층별 미니맵(내 위치 표시)

### 4.4 저택 맵 (10개 방, 2개 층)
**1층**: 현관 홀(계단) · 거실(벽난로, 피아노) · 식당(긴 식탁, 파티 흔적) · 주방(와인셀러 문) · 서재(시신 발견 장소) · 온실(분수, 식물) · 집사실
**2층**: 복도 · 주인 침실 · 객실 A(유진) · 객실 B(세라) · 다락방(옛 설계도)
- 2층은 **조사 2라운드부터** 열림 (진행 리듬 + 이동할 이유)

### 4.5 진행 단계 (총 약 40분, 방장이 진행 / 시간 끝나면 자동 진행)
대기실 → 사건 소개(역할 카드) → **조사 1 (12분, 1층)** → 중간 토론 (5분) → **조사 2 (10분, 2층 열림)** → 최종 토론 (8분) → 투표 → 진상 공개

### 4.6 사건 — "하얀 부엉이 저택 사건"
**도입**: 폭설로 고립된 송년 파티. 추리소설가 **한겨울**(62)이 "마지막 소설에 이 자리의 누군가의 진실을 썼다"고 발표한 지 두 시간 뒤, 밤 11시 30분 서재에서 숨진 채 발견된다. 머리 뒤에 상처. 서재 문은 안에서 잠겨 있지 않았다.

**진상 (반전)**: 서재는 진짜 현장이 아니다.
- 10:30 편집자 유진이 원고를 훔치려고 한겨울의 위스키에 수면제를 탄다
- 11:05 한겨울은 졸린 채 전 부인 세라를 온실로 불러 "소설에 네 뺑소니를 썼다"고 말한다
- 11:10 말다툼 끝에 세라가 밀치고, 비틀거리던 한겨울이 분수대 모서리에 머리를 부딪혀 숨진다
- 11:15~11:25 이 집을 직접 설계한 세라는 비밀 통로로 시신을 서재로 옮긴다 (수면제를 탄 사람에게 혐의가 가도록)
- 11:00 유진이 서재에 들어갔을 때 **한겨울은 이미 서재에 없었다** (유진은 원고만 훔쳐 나옴)

**범인: 전 부인 세라.** 첫 번째로 의심받는 사람은 수면제를 탄 유진이 되도록 설계.

**역할 4명 — 모두 수상함**
| 역할 | 공개 정보 | 숨기는 짓 (범인 아님 3명) | 수상한 흔적 | 그가 본 것 (시간표 조각) |
|---|---|---|---|---|
| 차유진 · 편집자 | 한겨울의 담당 편집자, 이번 책으로 출판사를 옮긴다는 통보를 받음 | 10:30 위스키에 수면제, 11:00 서재 금고에서 원고 훔침 | 객실 A 가방 속 수면제 병, 원고 뭉치, 서재 위스키 잔 | 11:00 서재에 들어갔을 때 **책상이 비어 있었다** (가장 결정적이지만 밝히면 자기가 의심받음) |
| 한별 · 조카 | 유일한 친척, 상속인 | 10:50~11:25 주인 침실에서 유언장을 뒤지다 꽃병을 깸 | 깨진 꽃병, 유언장 초안("한별 몫 축소"), 은색 링 귀걸이 | 11:20 침실(서재 바로 위)에서 **벽 안쪽에서 무언가 끄는 소리**를 들음 |
| 도윤 · 집사 | 20년 근무, 저택 구조를 잘 앎 | 수년간 와인을 빼돌려 횡령. 그날 해고 통보받음 | 집사실 장부, 해고 메모, 사라진 흰 장갑 한 짝(와인셀러에서 발견) | 11:05 주방 창으로 **긴 머리 여성**이 온실 쪽으로 가는 뒷모습을 봄 |
| 세라 · 전 부인 (범인) | 건축가, 20년 전 이혼 | (진상 참조) | 진주 귀걸이 한 짝(비밀 통로), 젖은 숄(객실 B), 원고 속 '뺑소니' 장(유진 가방) | 거짓 알리바이: "11시부터 객실에서 쉬었다" |

**증거 (약 20개) — 조합 규칙**
- 현장 조작 증명: 서재 시신 주변에 **피가 거의 없음** + 시신 신발 밑창에 **온실 흙과 꽃잎** + 온실 분수대 모서리의 **닦아낸 핏자국** → "서재는 현장이 아니다"
- 이동 경로: 서재 책장 "어긋난 책" → **비밀 통로** 발견 → 통로 바닥 **끌린 자국** + **진주 귀걸이 한 짝**
- 통로를 아는 사람: 다락방 **옛 설계도** (설계자 서명 "세라") + 집사 도윤도 앎 → 후보 2명(도윤, 세라)
- 귀걸이 주인: 귀걸이를 하는 사람은 한별(은색 링)·세라 → 거실 **파티 단체 사진**에서 세라의 진주 귀걸이 확인 → 교집합 = 세라
- 시간표: 유진의 "11시 책상이 비어 있음" + 도윤의 "11:05 여성이 온실로" + 한별의 "11:20 벽 속 끄는 소리" + 멈추지 않은 증거(온실 바닥 깨진 손목시계 11:10)
- 동기: 유진 가방의 원고 속 **'뺑소니' 장** — 세라의 과거를 암시 (원고를 찾으면 유진도 더 의심받는 양날의 검)
- 레드 헤링: 수면제 병·위스키 잔(유진), 유언장 초안·깨진 꽃병(한별), 횡령 장부·해고 메모·흰 장갑(도윤)
- 숨긴 장소: 서랍, 옷장, 가방, 화분 밑, 와인셀러, 금고(비밀번호 = 서재 책장의 한겨울 데뷔작 출간 연도)

**인원별 처리 (v1 유지)**: 3명 이하 → 빈 역할은 NPC 진술서 공개 / 5명 이상 → 조수 탐정

## 4.7 검토 후 정한 규칙 (제 판단 — 사용자 확인 필요 표시)
- **증거 숨기기 (제 판단)**: 증거는 두 종류.
  - *고정 증거* (가구·현장에 붙은 것: 핏자국, 끌린 자국, 시신 상태, 설계도 벽보, 단체 사진 액자 등) — 아무도 못 챙김, 누구나 조사 가능
  - *휴대 증거* (귀걸이, 숄, 수면제 병, 원고, 장갑, 메모 등) — v1처럼 챙기면 다른 사람은 못 봄
  - 추리 사슬마다 고정 증거로만도 풀리는 길이 최소 1개 있어야 함 (범인이 휴대 증거를 숨겨도 풀림). 범인이 아닌 사람도 자기 레드 헤링을 숨길 수 있음
- **외형·성별 (제 판단)**: 유진=남, 한별=여(단발, 은색 링 귀걸이), 도윤=남(집사복), 세라=여(**긴 머리**, 진주 귀걸이, 빨간 숄). 전부 블록 캐릭터에 직접 그려 넣음 (4.2 참조)
- **파티 단체 사진**: 거실 액자(고정 증거). 조사하면 픽셀 그림 카드로 표시 — 블록 캐릭터 4명 + 한겨울이 나란히 선 장면을 렌더해 캡처, 세라의 진주 귀걸이가 보이게
- **재접속 (제 판단)**: 필요. 폰 화면 잠금/앱 전환으로 끊겨도 같은 방 코드로 다시 들어오면 **같은 캐릭터**로 복귀. 브라우저에 저장한 고유 ID로 식별, 방장이 전체 상태 재전송. 방장 이탈 시 방 종료는 v1과 동일
- **비밀 통로 (제 판단)**: 세라와 도윤은 역할 카드에 "통로를 안다"가 적혀 있고 처음부터 사용 가능. 다른 사람은 책장을 조사해 발견해야 사용 가능, "공개"하면 모두 사용. 통로 안 끌린 자국·귀걸이는 고정/휴대 증거로 그대로 남음
- **범인 배정 (제 판단)**: 플레이어가 2명 이상이면 **범인(세라)은 반드시 플레이어**에게 배정, 나머지 역할은 무작위. 혼자일 때(테스트)만 세라가 NPC

## 5. 빌더에게 맡기는 것
- 방 크기·배치 좌표, 소품 선택과 배치 (방마다 15~30개, 증거는 소품 속에 자연스럽게)
- 조이스틱 UI 세부, 카메라 벽 투명 처리 방식
- 성능 최적화 방식 (정적 메시 병합, 층별 렌더 분리, 그림자 범위)
- 문구 다듬기 (역할 카드·증거 설명은 위 표의 사실관계를 지킬 것)

## 6. 알려진 한계 (v1과 동일)
- 방장이 나가면 방 종료, 엄격한 네트워크에선 P2P 실패 가능 (TURN 없음)
- 공개 저장소라 코드에서 범인이 보임 — 친구끼리 사용 전제
