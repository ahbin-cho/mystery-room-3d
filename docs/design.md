# 말랑 산장 살인사건 — 설계 메모

## 무엇을, 왜
친구들이 각자 집에서 폰으로 같은 3D 사건 현장에 접속해 즐기는 크라임씬(추리) 게임.
대화는 보이스톡/디스코드로 하고, 게임은 "나만 아는 정보 + 함께 뒤지는 3D 현장 + 투표"에 집중한다.

## 정한 것
- 장르: 크라임씬 (역할마다 비밀, 범인 1명, 마지막에 투표) — 사용자 선택
- 접속: 각자 폰, 방 코드로 입장 — 사용자 선택
- 인원: 4역할 기준. 3명 이하면 빈 역할은 NPC(진술서만 공개), 5명 이상은 "조수 탐정" — 제 판단
- 스타일 — 참고 노션 3개를 섞음 (제 판단)
  - 캐릭터/공간: 클레이모피즘 3D (무광 파스텔, 둥근 도형) — 3D 아이콘 모음집
  - 증거 카드: Halftone Dossier (크림색 사건 파일 + 도장) — 99가지 화풍
  - 증거 자세히 보기: Exploded Teardown (부품이 벌어지며 회전) — 3D teardown
- 기술: index.html 한 파일, Three.js, 서버 없음 — Winter Village 가이드 방식 유지
- 멀티: PeerJS(WebRTC). 방장 폰이 서버 역할, 무료 공용 중개 서버 사용, 계정/키 불필요

## 게임 흐름
대기실 → 사건 소개(역할 카드) → 조사 10분 → 토론 5분 → 투표 → 진상 공개 (방장이 단계 진행)

## 증거 규칙
- 반짝이는 물건 터치 → 가까이 가서 조사 → 내용을 내 수첩에 기록
- "챙기기"하면 현장에서 사라져 다른 사람은 못 봄 (범인이 숨길 수 있음)
- 챙긴 증거는 "모두에게 공개" 가능

## 알려진 한계
- 방장이 나가면 방이 끝남
- 일부 회사/학교 와이파이 등 엄격한 네트워크에서는 P2P 연결이 안 될 수 있음 (TURN 서버 미사용)
- 시나리오 1개 (한 번 풀면 끝) — 추가 시나리오는 SCENARIO 데이터만 바꾸면 됨
